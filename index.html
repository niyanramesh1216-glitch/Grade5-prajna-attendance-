Monthly lock rule

When a month is submitted, the demo prevents changes to attendance for that month, including in teacher mode.

Important: this is a front-end demo, not a secure production attendance system. Browser storage can be changed or cleared, and a shared client-side PIN is not secure. A real deployment needs a server, hashed passwords, role-based permissions, audit logs, and server-enforced monthly locks.
